# 和弦譜轉級數

上傳和弦譜（PDF、照片或文字），自動找出和弦並轉成數字或羅馬級數譜。

- 網址：https://bbshen1995-hash.github.io/chord-to-degree/
- 流程：上傳或拖曳檔案 → 自動找和弦 → 在「核對」圖上看色框（綠＝確定、橘＝沒把握、紅虛線＝疑似漏抓、藍＝手動）→ 點框修改或在空白處補和弦 → 下載成品圖或複製級數清單
- 文字型 PDF 直接讀文字層，準確度最高；掃描檔與照片用 OCR，上標升降記號與小字容易漏讀，需要核對
- 單一 HTML 檔，PDF 引擎（pdf.js）與 OCR（Tesseract.js）於使用時才從 CDN 載入
